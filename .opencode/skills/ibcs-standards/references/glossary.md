# IBCS Glossary

Terms are defined as used in IBCS v2.0. Rule IDs point to the reference file where the term is applied.

## A

**Abbreviation.** A shortened form of a term or measure name, standardized in a corporate glossary. Use short forms in column headers and longer forms in row headers where space allows. See UN 1.1.

**Absolute measure.** A measured quantity expressed in absolute units such as currency, kilograms, or number of elements; neither a share nor a quotient. See UN 3.1.

**Absolute variance.** The difference between two values of one measure from different scenarios, such as AC minus PL. Label with `Δ` plus the subtrahend (`ΔPL`) or with the explicit subtraction (`AC-PL`). See UN 4.1.

**Actual scenario.** Measured data about events in the present or past. Abbreviated `AC`; previous periods use `PY`. Visualized with a solid dark fill. See UN 3.2.

**Adjustment analysis.** An analysis that neutralizes special effects, such as currency, inflation, or seasonality, by recalculating one scenario with factors from another. See UN 4.4.

**Analysis.** The comparison and interpretation of data, including scenario, time-series, structure, and adjustment analyses. See UN 4.

**Annotation.** Explanatory text that provides additional context or explanation for a visual or visual component. Link it to the relevant component with an annotation reference. See UN 2.4 and SA 4.5.

**Annotation reference.** A consistently designed pair of markers linking an annotation to the value or position it explains. See UN 5.1.

**Assisting area.** A highlighted area used to group, separate, or emphasize parts of a chart or table. See UN 5.1.

**Assisting line.** A line used to highlight differences, separate or group data, or coordinate visual components across charts. See UN 5.1.

**Averaging, structural.** Calculation of an average value across structure categories, such as average sales per subsidiary. See UN 4.3.

**Axis.** The reference line for categories or values. Time categories run horizontally; structure categories run vertically. See UN 3.3 and UN 3.4.

**Axis, logarithmic.** A value axis using a logarithmic scale. Avoid it unless relative growth across several orders of magnitude is the analytical purpose; label it clearly. See CH 1.2.

**Axis, manipulated.** An axis that distorts the visual comparison, such as a truncated or logarithmic axis used without justification. See CH 1.

**Axis, truncated.** A value axis that does not start at zero. Avoid it; the common exception is indexed data with small deviations from 100%, with category labels at the 100% line. See CH 1.1.

## B

**Brinton, Willard Cope.** Author of *Graphic Methods for Presenting Facts* (1914), cited as a source for perceptual principles.

**Business communication.** See **Business reporting**.

**Business measure.** See **Measure**.

## C

**Category.** An element of a dimension, such as a specific month, country, product, or scenario.

**Category label.** A text label identifying a category on an axis. Write it horizontally where possible. See UN 2.3.

**Category width.** The space allocated to one category on an axis. It can encode the period type; longer periods get wider segments. See UN 3.3.

**Chart.** A graphical visual in which components such as columns, bars, and lines represent data. See EX 1.1.

**Chart, area.** A chart with filled areas. IBCS v2.0 does not yet define a specific layout concept; derive it from the column and line notation. See EX 1.1.

**Chart, boxplot (range).** A chart showing a range or distribution. No specific IBCS notation concept yet; derive it from the bar notation. See EX 1.1.

**Chart, bubble (portfolio).** A chart with two value axes and bubbles whose area encodes a third measure. See EX 1.1.

**Chart, calculation waterfall.** A vertical waterfall whose base and totals bars represent a calculation scheme and whose contribution bars represent additions and subtractions. See EX 1.1.

**Chart, embedded.** A chart component embedded in a table, such as table bars, sparklines, or traffic lights. See CO 4.4.

**Chart, extended.** A chart that arranges additional charts next to the primary chart by extending the category axis, often for benchmarks or context. See CO 4.3.

**Chart, funnel.** A chart whose area often does not correspond to the values. Replace it with a suitable chart unless the shape itself carries meaning. See EX 2.3.

**Chart, grouped bar.** A vertical chart with overlapping bars for a primary and a reference scenario. See EX 1.1.

**Chart, grouped column.** A horizontal chart with overlapping columns for a primary and a reference scenario. See EX 1.1.

**Chart, growth waterfall.** A horizontal waterfall showing changes in a stock measure between points in time. See EX 1.1.

**Chart, horizontal.** A chart with a horizontal category axis, typically used for time series. See EX 1.1.

**Chart, horizontal pin.** A chart of relative variances over time, using very thin columns with heads. See EX 1.1.

**Chart, horizontal variance waterfall.** A horizontal waterfall showing period or scenario variances as contributions. See EX 1.1.

**Chart, line.** A chart of one or more lines over time. Use it for trends, seasonality, or many data points; avoid it for few values. See EX 1.1.

**Chart, map.** A chart using geographic areas. Colored areas are appropriate only for area-related data. See CH 3.3.

**Chart, multi-tier.** A combined chart with a secondary chart parallel to the primary chart's category axis, often used for variances. See CO 4.2.

**Chart, overlay.** A combined chart in which two or more basic charts overlap on the same category axis. See CO 4.1.

**Chart, pie.** A circular chart dividing a total into sectors. Replace it with bars or stacked columns except for narrow map applications with few values. See EX 2.1.

**Chart, radar (spider, net).** A circular chart with axes radiating from a center. It has no advantage over bars for typical business data; use only when the circular arrangement has meaning. See EX 2.3.

**Chart, ring.** A pie-like chart with a hole. Replace it for the same reasons as a pie chart. See EX 2.1.

**Chart, scattergram.** A chart positioning points in a two-dimensional coordinate system with two value axes. See EX 1.1.

**Chart, single bar.** A vertical chart with one bar per structure category for one period or point in time. See EX 1.1.

**Chart, single column.** A horizontal chart with one column per time period or point in time for one data series. See EX 1.1.

**Chart, spaghetti.** A line chart with more than three or four intersecting lines. Replace it with small multiples unless exact height comparison is required. See EX 2.4.

**Chart, stacked bar.** A vertical chart whose bars are divided into segments for multiple data series. Use only when all values have the same sign. See EX 1.1.

**Chart, stacked column.** A horizontal chart whose columns are divided into segments for multiple data series. Use only when all values have the same sign. See EX 1.1.

**Chart, vertical.** A chart with a vertical category axis, typically used for structure analyses. See EX 1.1.

**Chart, vertical pin.** A chart of relative variances by structure category, using very thin bars with heads. See EX 1.1.

**Chart, vertical variance waterfall.** A vertical waterfall showing structure variances as contributions. See EX 1.1.

**Chart selection matrix.** A decision aid mapping analytical questions and data conditions to chart types. See `chart-and-table-catalog.md`.

**CHECK principles.** The notation principles CH 1–5: avoid manipulated axes, avoid manipulated components, avoid misleading representations, use the same scales, show data adjustments. See `rules/ch-check.md`.

**Collectively exhaustive.** A set of elements that covers all aspects of a superordinate topic. Together with mutually exclusive, it forms a MECE structure. See ST 3.

**Column types.** Categories of table columns with similar content: row header, scenario, variance, time, measure, structure, of which, remainder, percent of, totals, hierarchical, nested. See EX 1.2.

**Composition.** The principles SAY, STRUCTURE, EXPRESS, and CONDENSE that govern message, storyline, visual choice, and density. See `composition-playbook.md`.

**Conceptual principles.** The SAY and STRUCTURE principles, based on the work of Barbara Minto and others. See `composition-playbook.md`.

**CONDENSE principles.** The composition principles CO 1–5: small elements, maximize space, add data, add visual components, add visuals. See `rules/co-condense.md`.

**Consistent elements.** Items, statements, wording, and visualizations that share the same type and appearance within a group. See ST 1.

**Currency.** Monetary unit. Use ISO 4217 three-letter codes (EUR, CHF, USD, GBP) and consistent metric prefixes (k, m, b). See UN 1.2.

## D

**Dashboard.** A compilation of interactive statistics or visuals covering a business topic. IBCS applies to static and interactive dashboards. See `framework.md`.

**Data, expected.** See **Forecast scenario**.

**Data, fictitious.** Data that has not materialized, such as plan or budget. Visualized with outlined areas. See **Plan scenario**.

**Data, measured.** Actual data about events that have occurred. Visualized with a solid dark fill. See **Actual scenario**.

**Data compilation.** A collection of data without a predetermined message; also called statistics. See `framework.md`.

**Data label.** A text label assigning a data value to a visual component. Write it horizontally, next to the component, with at most three digits where possible. See UN 2.3 and SI 5.

**Data-ink ratio.** The proportion of a graphic's ink devoted to non-redundant data information. See SI.

**Date.** A calendar reference. Use ISO 8601 `YYYY-MM-DD` for consistency. See UN 1.2.

**Deductive reasoning.** A logical flow from a statement through a comment to a conclusion, answering “why” after the key message. See ST 4.1.

**Detection.** A message that states a checkable fact or finding. See SA 3.1.

**Difference marker.** A marker highlighting the distance between two assisting lines, often with a color for desirable, undesirable, or neutral impact. See UN 5.1.

**Dimension.** A set of categories that describe one characteristic of the data, such as measures, scenarios, periods, or structure. See `framework.md`.

## E

**Exhaustive elements.** See **Collectively exhaustive**.

**Explanation.** A message that gives reasons for a detection. See SA 3.1.

**EXPRESS principles.** The composition principles EX 1–5: appropriate visuals, replace inappropriate charts, replace inappropriate representations, add comparisons, explain causes. See `rules/ex-express.md`.

## F

**Few, Stephen.** Author of *Show Me the Numbers* (2012), cited as a source for perceptual principles.

**Footnote.** Additional descriptive detail at the bottom of a page, such as definitions, sources, or retrieval dates. See UN 2.5.

**Forecast scenario.** Expected data that is still partly fictitious but based on measured data. Abbreviated `FC`; visualized with an outlined area plus hatching. See UN 3.2.

## G

**Gauge.** A dial-like visual for a single value. Replace it with bars or columns except for real-time monitoring with a clear target and semantic deviation coloring. See EX 2.2.

**Glossary.** A corporate list of terms and abbreviations with definitions, used to unify terminology. See UN 1.1.

## H

**Hichert, Rolf.** Co-author of IBCS and originator of the semantic notation principles.

**Hierarchical structure.** A structure with levels of parent and child categories, used to organize content and tables. See ST 4 and ST 5.

**Highlighting ellipse.** A blue ellipse used to emphasize a specific value. See UN 5.1.

**Highlighting marker.** A consistently designed visual device for emphasizing a message, difference, trend, value, reference, or annotation. See UN 5.1.

## I

**IBCS Association.** The not-for-profit organization that maintains the IBCS Standards.

**Indexing, structural.** Depicting values relative to a reference category set to 100%. See UN 4.3.

**Indexing, temporal.** Depicting a time series relative to a reference period set to 100%. See UN 4.2.

**Inductive reasoning.** A logical group of homogeneous, non-overlapping, collectively exhaustive arguments culminating in a key message. See ST 4.2.

**Information density.** The amount of relevant information presented per page or visual. Increase it without sacrificing legibility. See CO.

**Interactive analytic application.** A management information system or dashboard that delivers reporting interactively. See `framework.md`.

## L

**Legend.** A label identifying a data series. Integrate it into the chart where possible; write it horizontally. See UN 2.3.

**Logical flow.** Deductive reasoning that answers “why” after the key message. See ST 4.1.

**Logical group.** Inductive reasoning with homogeneous, non-overlapping, exhaustive arguments. See ST 4.2.

## M

**MAA (moving annual average).** A moving analysis that calculates an average over the previous twelve months. See UN 4.2.

**Management information system.** See **Interactive analytic application**.

**Marker.** A visual device for highlighting, scaling, or flagging outliers. See UN 5.

**MAT (moving annual total).** A moving analysis that accumulates values over the previous twelve months. See UN 4.2.

**Measure.** A quantitative metric used to evaluate performance, such as sales, profit, margin, or headcount. See **Measure, absolute** and **Measure, relative**.

**Measure, absolute.** A measured quantity in absolute units, such as currency, kilograms, or number of elements. See UN 3.1.

**Measure, flow.** A measure that refers to an entire period, such as sales or costs. See `framework.md`.

**Measure, relative (ratio).** A quotient of two absolute measures, such as return on sales. See UN 3.1.

**Measure, stock.** A measure captured at a point in time, such as inventory or headcount. See `framework.md`.

**Measure, value.** A measure expressed as a value, such as profit. See UN 3.1.

**Measure, volume.** A measure expressed as a quantity, such as shipments. See UN 3.1.

**MECE.** Mutually exclusive, collectively exhaustive. The standard for non-overlapping, exhaustive structures. See ST 2 and ST 3.

**Message.** The statement a report or page conveys: a detection, explanation, suggestion, or other statement. See SAY.

**Minto, Barbara.** Author of *The Pyramid Principle* (2002), cited as a source for SAY and STRUCTURE.

**Moving analysis.** An analysis over a moving period, usually the previous twelve months, marked with a tilde prefix. See UN 4.2.

**Mutually exclusive.** Elements that do not overlap. Together with collectively exhaustive, it forms a MECE structure. See ST 2.

## N

**Non-overlapping elements.** Elements that are mutually exclusive and do not cover the same aspect. See ST 2.

**Normalizing, structural.** Comparing shares of a whole, such as country sales as a percentage of Europe sales, with an assisting 100% line. See UN 4.3.

**Notation.** The formal syntax and semantics for representing information, covering terminology, text elements, dimensions, analyses, and markers. See `framework.md`.

**Notation manual.** See `framework.md`.

**Note.** A text element that explains or structures content; visualize its structure clearly. See ST 5.3.

**Number.** A numerical value. Unify formats; use at most three digits in charts and four in tables; use metric prefixes where helpful. See UN 1.2 and SI 5.2.

## O

**Of which.** A column or row showing details of an aggregated value that do not total to it. Design it differently from normal columns/rows and position it next to the parent. See EX 1.2.

**Outlier marker.** A marker indicating that a value exceeds the visible scale; often a triangle instead of a pin head. See UN 5.3 and CH 4.4.

## P

**Period.** A time frame such as a day, week, month, quarter, or year. See `framework.md`.

**Physical unit.** A non-monetary unit such as kg, t, m, or km. Use SI units consistently. See UN 1.2.

**Pin.** A very thin column or bar used for relative variances, with a head showing the scenario analyzed. See UN 4.1 and EX 1.1.

**Plan scenario.** Predicted, not materialized data, such as Plan or Budget. Abbreviated `PL` or `BU`; visualized with an outlined area. See UN 3.2.

**Playfair, William.** Author of *The Commercial and Political Atlas* (1786), cited as a source for perceptual principles.

**Presentation.** Presentation material such as slides and handouts. IBCS visual rules apply to the material, not the spoken delivery. See `framework.md`.

## R

**Ranking.** A structure analysis ordering categories by value, alphabet, or date, often marked with an arrow. See UN 4.3.

**Ratio.** See **Measure, relative**.

**Ratio tree.** A multi-chart that breaks a ratio into its components in a tree shape. See CO 5.2.

**Reference arrowhead.** An arrowhead marking an index or benchmark reference, with the reference label next to it. See UN 5.1.

**Remainder bar.** A bar accumulating the smallest categories that cannot be shown individually, separated by a wider gap. See EX 1.1.

**Report.** See `framework.md`.

**Report page.** See `framework.md`.

**Reporting.** See **Business reporting**.

**Reporting unit.** The entity, organizational unit, line of business, project, or filter described in title line 1. See UN 2.2.

**Row types.** Categories of table rows with similar content: column header, measure, structure, of which, remainder, percent of, totals, hierarchical, nested. See EX 1.2.

## S

**SAY principles.** The composition principles SA 1–5: know objectives, introduce message, deliver message, support message, summarize message. See `rules/sa-say.md`.

**Scale band.** A light-colored band between a scaling line and the category axis, used to compare charts with different scales. See UN 5.2 and CH 4.3.

**Scaling marker.** A marker that indicates reference values, scaling factors, or scale differences, such as a scale band. See UN 5.2.

**Scenario.** A data layer or version to compare, such as Actual, Previous year, Plan, Budget, or Forecast. See `framework.md` and UN 3.2.

**Scenario analysis.** Comparison of scenarios and calculation of absolute and relative variances. See UN 4.1.

**Scenario comparison.** Placing data from different scenarios next to each other, often with overlapped grouped columns/bars or scenario triangles. See UN 4.1.

**Scenario triangle.** A triangle representing a reference scenario behind a primary column or bar. See UN 4.1.

**Selecting.** A structure analysis choosing maximal or minimal categories, such as top ten or first quartile. Visualization is deferred in v2.0. See UN 4.3.

**Semantic notation.** The principle that similar content looks similar and different content looks different, with consistent meaning for color, fill, shape, and position. See UN.

**Share.** A relative measure in which the numerator and denominator have the same absolute measure, such as consultants as a percentage of employees. See UN 3.1.

**SIMPLIFY principles.** The notation principles SI 1–5: avoid unnecessary elements, avoid decorative styles, replace with cleaner layout, avoid redundancies, avoid distracting details. See `rules/si-simplify.md`.

**Small multiple.** One of several charts of the same type and scale placed next to each other for comparison. See CO 5.1.

**Sparkline.** A small line chart embedded in a table. Use only with proper scaling; otherwise omit it. See CO 4.4.

**Speedometer.** See **Gauge**.

**Static report.** A printed or non-interactive report. IBCS applies to static and interactive reporting. See `framework.md`.

**Statistics.** See **Data compilation**.

**Structure analysis.** Analysis of structural data such as regions, products, customers, or channels, including averaging, ranking, selecting, indexing, and normalizing. See UN 4.3.

**Structure dimension.** A dimension other than measures, scenarios, and periods, typically hierarchical, such as region or product. See `framework.md`.

**STRUCTURE principles.** The composition principles ST 1–5: consistent elements, non-overlapping elements, collectively exhaustive elements, hierarchical structures, visualize structure. See `rules/st-structure.md`.

**Subtitle.** A text element identifying a page segment or visual within a page with multiple visuals. See UN 2.2.

**Suggestion.** A message recommending a decision or action. See SA 3.1.

## T

**Table.** A visual arranging data in rows and columns. Tables are for lookup and precision; charts are for comparison and message. See EX 1.2.

**Table, combined.** A table serving more than one analytical purpose, using multiple column and/or row types. See EX 1.2.

**Table, cross.** A table combining structure columns with structure rows. See EX 1.2.

**Table, time series.** A table combining time columns with measure or structure rows. See EX 1.2.

**Table, variance.** A table combining scenario and variance columns with measure or structure rows. See EX 1.2.

**Table bar.** A bar chart embedded in a table, aligned with the table rows. See CO 4.4.

**Term.** A word or phrase with a defined meaning. Standardize terms and abbreviations in a glossary. See UN 1.1.

**Terminology.** The set of terms and abbreviations used in reporting. See UN 1.

**Time.** The dimension of periods and points in time. Time moves left-to-right on horizontal axes and in table columns. See UN 3.3.

**Time dimension.** The dimension containing periods and points in time. See `framework.md`.

**Time period.** A specific time frame, such as 2026, 2026-Q1, or 2026-03. See `framework.md`.

**Time series analysis.** Analysis of data over time, including year-to-date, year-to-go, moving, and indexed analyses. See UN 4.2.

**Title.** A descriptive text element identifying a page or visual. Page titles have three lines: who, what, when. See UN 2.2.

**Traffic light.** A red/yellow/green status indicator. Use only for binary or threshold states where magnitude is irrelevant; otherwise use bars. See EX 2.5 and CO 4.4.

**Trend arrow.** An arrow from the first to the last period of a trend, with the arrowhead in the time direction and an optional calculation label. See UN 5.1.

**Tufte, Edward.** Author of *The Visual Display of Quantitative Information* (2011), cited as a source for perceptual principles.

## U

**UNIFY principles.** The notation principles UN 1–5: terminology, text elements, dimensions, analyses, markers. See `rules/un-unify.md`.

## V

**Variance.** The difference between two values of one measure from different scenarios. See **Absolute variance** and **Relative variance**.

**Variance, absolute.** See **Absolute variance**.

**Variance, integrated.** A variance displayed within the columns or bars of a primary chart. See CO 4.1.

**Variance, relative.** The absolute variance expressed as a percentage of the subtrahend, such as `(AC-PL)/PL*100`. See UN 4.1.

**Visual.** See `framework.md`.

**Visual component.** See `framework.md`.

**Visual integrity.** The quality of presenting information truthfully and without misleading visual impressions. See CHECK.

**Visualization.** The choice and construction of a visual representation, including chart and table type. See EXPRESS.

## Y

**Year-to-date analysis (YTD).** An analysis from the beginning of the (fiscal) year to the present, marked with an underscore prefix. See UN 4.2.

**YTD.** See **Year-to-date analysis**.

**YTG (year-to-go).** An analysis from the present to the end of the (fiscal) year, marked with an underscore suffix. See UN 4.2.

## Z

**Zelazny, Gene.** Author of *Say It with Charts* (2001), cited as a source for perceptual principles.
