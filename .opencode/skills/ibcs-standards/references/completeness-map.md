## Coverage summary

The “Worked example” column points to the best available illustration. A label marked **(avoidance check)** means the example demonstrates the rule through its “What would be wrong” list rather than a positive design. **No dedicated example** means none of the five examples exercises the rule directly; use the rule file as the authority. Not every rule has a positive worked example.

- 35 top-level rules and 105 sub-rules.
- Every sub-rule has a detailed entry in a rule file and a row in this map.
- Source pages follow the printed page numbers 1–169.
- The harness verifies the ID set against the spec inventory and rejects duplicates, extras, and omissions.

## Explicit gaps (not specified in v2.0)

- Comprehensive measure-type notation beyond absolute/relative.
- Visualization of adjustment analyses.
- Visualization of selecting in structure analyses.
- Specific notation for area charts.
- Specific notation for boxplot/range charts.
- Specific notation for charts with two value axes.
- Additional scaling visualizations beyond scale bands.

## Verification procedure

1. Count the detailed headings in each rule file: SI 14, UN 18, CH 15, SA 14, ST 14, EX 14, CO 16.
2. Run `python scripts/verify_skill.py`. The harness parses the spec inventory and this table, then compares the two ID sets.
3. Spot-check random IDs against the PDF: title, Requirement, source page.
4. Confirm every row has a non-empty checklist item and worked-example reference.
